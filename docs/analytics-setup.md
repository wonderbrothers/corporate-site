# GTM / GA4 導入手順（WBコーポレートサイト）

最終更新: 2026-08-30

コード側の実装は完了済み。あとは Google 側で ID を発行し、`GTM_ID` を差し替えるだけで計測が始まる。

---

## 0. 実装済みの内容（コード側）

| ファイル | 変更内容 |
| --- | --- |
| `src/layouts/Base.astro` | `GTM_ID` 定数を追加。`<head>` の最上部に gtm.js スニペット、`<body>` 直後に noscript の iframe を出力。全4ページ（`/`, `/contact/`, `/privacy/`, `/404`）に自動で入る |
| `src/pages/contact.astro` | フォーム送信が成功したタイミングで `dataLayer` に `contact_submit` イベントを push |

**設計上のポイント**

- `GTM_ID` が空文字の間は、スニペットも noscript も **一切出力されない**。ID 未発行のままビルド・デプロイしても安全。
- GA4 の測定ID（`G-XXXXXXXXXX`）は **コードに書かない**。GTM の管理画面側で設定する。これにより、今後 GA4 の設定変更・広告タグ・ヒートマップ等を追加するときにコード改修とデプロイが不要になる。
- お問い合わせフォームは送信後にページ遷移しない（同一ページ内でサンクスメッセージを表示する）実装のため、ページビューでは送信完了を計測できない。そのため `contact_submit` というカスタムイベントを `dataLayer` に流している。

## STEP 1. GA4 プロパティを作成して測定IDを取得

1. <https://analytics.google.com/> にアクセス（会社の Google アカウントで）。
2. 左下の歯車 **[管理]** → **[アカウントを作成]**
   - アカウント名: `株式会社ワンダーブラザース`
   - データ共有設定: 既定のままで可
3. 続けてプロパティを作成
   - プロパティ名: `wonder-bros.com`
   - レポートのタイムゾーン: **日本**
   - 通貨: **日本円 (JPY)**
4. ビジネスの詳細・利用目的を選択（任意項目。「見込み顧客を獲得する」あたりを選ぶ）
5. データストリームの設定で **[ウェブ]** を選択
   - ウェブサイトの URL: `https://wonder-bros.com`
   - ストリーム名: `WBコーポレートサイト`
   - **拡張計測機能は ON のまま**（スクロール、離脱クリック、ファイルダウンロード等を自動計測してくれる）
6. 作成後に表示される **測定ID `G-XXXXXXXXXX` をコピーして控える**
   - 後から確認する場合: [管理] → [データストリーム] → 対象ストリームをクリック → 右上に表示

> この画面で「実装手順」としてタグの貼り付けを促されるが、**ここでは何もしなくてよい**。GTM 経由で設定する。

## STEP 4. GTM に GA4（Googleタグ）を設定

GTM 管理画面のワークスペースで:

1. 左メニュー **[タグ]** → **[新規]**
2. タグ名を `GA4 - Google タグ` に変更（左上のタイトル部分）
3. **[タグの設定]** をクリック → タグタイプ **[Google タグ]** を選択
   - **タグID**: STEP 1 の測定ID `G-XXXXXXXXXX` を入力
   - 「設定パラメータ」は初期状態のままで可
4. **[トリガー]** をクリック → **[初期化 - All Pages]**（`Initialization - All Pages`）を選択
   - ページビュー用トリガーより先に発火するため、Google タグは初期化トリガーを使うのが推奨
5. 右上の **[保存]**

> これだけで **page_view / scroll / click / file_download など GA4 の拡張計測がすべて動く**。ページビュー用のタグを別途作る必要はない。

## STEP 5. お問い合わせ送信（contact_submit）を計測

### 5-1. トリガーを作成

1. 左メニュー **[トリガー]** → **[新規]**
2. トリガー名: `CE - contact_submit`
3. **[トリガーの設定]** → **[カスタムイベント]**
   - イベント名: `contact_submit`（コードから push している名前と完全一致させる）
   - 「すべてのカスタム イベント」を選択
4. **[保存]**

### 5-2. GA4 イベントタグを作成

1. 左メニュー **[タグ]** → **[新規]**
2. タグ名: `GA4 - contact_submit`
3. **[タグの設定]** → タグタイプ **[Google アナリティクス: GA4 イベント]**
   - **測定ID**: `G-XXXXXXXXXX`（または STEP 4 で作った Google タグを参照）
   - **イベント名**: `contact_submit`
   - （任意）イベントパラメータに `form_name` を追加し、値に `{{DLV - form_name}}` を設定
4. **[トリガー]** → 5-1 で作った `CE - contact_submit` を選択
5. **[保存]**

### 5-3.（任意）データレイヤー変数を作る

`form_name` をパラメータとして送りたい場合のみ:

1. 左メニュー **[変数]** → ユーザー定義変数の **[新規]**
2. 変数名: `DLV - form_name`
3. 変数タイプ: **[データレイヤーの変数]**
   - データレイヤーの変数名: `form_name`
4. **[保存]**

## STEP 6. プレビューで動作検証（公開前に必須）

1. GTM 右上の **[プレビュー]** をクリック
2. URL に `https://wonder-bros.com/` を入力 → **[Connect]**
3. 新しいタブでサイトが開き、Tag Assistant のデバッグ画面が並ぶ
4. 確認すること
   - トップページで `GA4 - Google タグ` が **Tags Fired** に入っているか
   - `/contact/` に移動してフォームを実際に送信し、左側のイベント列に **`contact_submit`** が現れ、`GA4 - contact_submit` が発火しているか
5. あわせて GA4 側でも確認: [管理] → **[DebugView]** に `page_view` と `contact_submit` がリアルタイムで流れてくる

> 検証用の送信で実際にお問い合わせメールが飛ぶので、本文に「テスト送信」と明記しておく。

## STEP 7. GTM コンテナを公開

1. GTM 右上の **[公開]**
2. バージョン名: `GA4 導入 / contact_submit 計測`
3. **[公開]** を実行

これで一般ユーザーの計測が開始される。

## STEP 8. GA4 でキーイベント（旧コンバージョン）に登録

GA4 では「コンバージョン」は **キーイベント** という名称に変わっている。

1. GA4 → **[管理]** → データの表示 **[キーイベント]**
2. 右上の **[新しいキーイベント]**
3. イベント名に `contact_submit` を入力 → **[保存]**

> 別ルートとして、[管理] → [イベント] の一覧に `contact_submit` が現れた後に「キーイベントとしてマークを付ける」を ON にしてもよい。ただし一覧に出るまで最大24時間かかるため、上の「新しいキーイベント」から先に登録しておくのが早い。

登録後、レポートに反映されるまで最大24時間程度かかる。

## 補足

### 計測を一時停止したいとき

`src/layouts/Base.astro` の `GTM_ID` を空文字 `""` に戻してデプロイすれば、タグの出力自体が止まる。GTM 側のコンテナを触る必要はない。

### 今後タグを追加したいとき（広告・ヒートマップ等）

GTM の管理画面でタグを追加して公開するだけでよい。コードの改修とデプロイは不要。

### イベント名を追加したいとき

`src/pages/contact.astro` と同じ要領で、任意の箇所に以下を書けば GTM のカスタムイベントトリガーで拾える。

```js
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({ event: "任意のイベント名", 任意のパラメータ: "値" });
```
